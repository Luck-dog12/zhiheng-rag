## 早期模拟服务下的 Edge 流程（历史）

使用本机安装的 Microsoft Edge，没有下载 Chrome 或 Chrome CLI。合成账号登录后完成：

1. 上传 Markdown，观察后台入库和已就绪状态。
2. 查看分块、原始段落及替换记录：“它的容量”变为“可乐的容量”，原文保留“它”。
3. 首轮提问及追问完成 SSE 输出；展开引用时重新请求分块接口验证当前权限和版本，返回 200。

6. 390 × 844 窄屏可切换历史、新建对话、查看导航和发送区域；已修复底部文字重叠。
7. 最终页面刷新后控制台没有错误或警告。未登录时 `/auth/me` 返回 401 属于预期登录检查。
